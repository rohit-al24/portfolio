# Galaxy Asset Placeholder

Drop your own animated Milky Way here. The section automatically uses the
best available source, in this order:

1. `maroon-milkyway.mp4` — recommended (small, muted, looping video).
2. `maroon-milkyway.gif` — fallback animated image.
3. A built-in CSS maroon galaxy — used automatically when neither file exists.

Guidelines:
- Use a **maroon / crimson / burgundy** palette to match the ROHIT.SK identity.
- Keep the file small (a 1080p MP4 under ~5 MB is ideal).
- The section uses `object-fit: cover`, so any aspect ratio works — the galaxy
  is centered and cropped, never stretched or distorted.
